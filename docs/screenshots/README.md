# Screenshots

`dashboard-suggested.png` shows the desktop app's mock-tier dashboard (the
e2e scenario's invented mods) at 1280x800, light theme, with the first-run
notice dismissed, the recommended rules imported (step 1 done), Suggested
selected and Apply as the current step.

The `mods-page/` images show the Mods page's activate/deactivate, move and
rescan flows, including the Apply dialog, the sort buttons, the Added and
Removed marks, the outside-change note and the "This isn't your active order
yet." note, as embedded in [`docs/desktop.md`](../desktop.md). They are
mock-tier captures at the same size, dark theme; `sort-toggle.png` and
`order-not-applied-note.png` are crops of the page.

`mods-page/groups-view.png` and `mods-page/search-highlight.png` show the Active
list in Groups view (folders, colours) and with a search marked, dark theme,
1280x800 (`search-highlight.png` is a crop of the list).
`mods-page/apply-outside-change-confirm.png` is the Apply dialog's confirm
section after the file changed outside Rimmerge and
`mods-page/outside-change-hint.png` is the note shown on the other pages (a crop).
`mods-page/copy-groups-preview.png` is the Copy groups from another profile
dialog with its Merge preview, at 1900x900 like the two images below.

`mods-page/groups-and-bulk-actions.png` and
`mods-page/bulk-add-to-group-dialog.png` show the Groups panel and the bulk
actions in [`docs/desktop.md`](../desktop.md); they are dark-theme captures at
1900x900, because the panel is a column only from 1,800 pixels wide.
`order-page/import-from-save.png` is the Load order page's "Import from a
save" list, dark theme, 1280x800.

Every image here is generated by
`apps/desktop/e2e/screenshots/docs.spec.ts`, which drives the mock-IPC
scenario (`apps/desktop/e2e/fixtures/scenario.ts`) into each state. From
`apps/desktop`:

```sh
RIMMERGE_DOCS_SCREENSHOTS=1 bun run e2e:screenshots -- docs.spec.ts
```

In PowerShell, set the variable for the run and clear it afterwards, so a
later locale-tour run in the same window does not regenerate the docs
images too:

```powershell
$env:RIMMERGE_DOCS_SCREENSHOTS = "1"; bun run e2e:screenshots -- docs.spec.ts; Remove-Item Env:RIMMERGE_DOCS_SCREENSHOTS
```

The spec is skipped without that variable and is not part of `bun run e2e`.
It uses the same dedicated port (5183) as `bun run e2e` and the locale
tour, so never run it at the same time as either. Two runs on the same
machine write identical files (font rendering differs between machines);
commit the PNGs it changes along with the UI change that caused them.
